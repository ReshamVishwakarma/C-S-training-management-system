# C&S Training Management Portal

Learning Management System (LMS) built using Frappe Framework for C&S Electric.

## Roles

- LMS Admin
- Trainer
- Trainee

## Core Modules

- Course Management
- Training Sessions
- Enrollment Management
- Attendance Tracking
- Assessments & Quizzes
- Certificate Generation
- Feedback System
- Analytics & Reports

## Technology Stack

- Frappe Framework
- MariaDB
- Python
- JavaScript
