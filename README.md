# C&S Training Management System

Learning Management System (LMS) built using Frappe Framework for C&S Electric.

## Roles

- LMS Admin
- Trainer
- Trainee

## Modules

- Course Management
- Training Sessions
- Enrollment
- Attendance
- Assessments
- Certificates
- Feedback
- Reports & Dashboards

## Tech Stack

- Frappe Framework
- MariaDB
- Python
